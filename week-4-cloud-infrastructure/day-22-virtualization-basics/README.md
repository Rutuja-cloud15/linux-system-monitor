#Day 22: Virtualization & Cloud Foundations

### Core Revision Notes
* **Virtualization**: The architectural abstraction layer that divides physical bare-metal hardware resources into independent, isolated digital environments.
* **Hypervisor**: The virtualization management engine responsible for allocating memory, storage, and processing power across guest systems.
* **VM vs. Container Matrix**:
  * **VMs** isolate entire operating systems (heavyweight, hardware-level abstraction).
  * **Containers** isolate individual application processes (lightweight, OS-level abstraction).
